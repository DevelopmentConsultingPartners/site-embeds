# site-embeds

Hosted code for interactive pages on the Development Consulting Partners website.
Each Squarespace page holds only a short **loader** in a Code Block; the page itself
loads from GitHub Pages, so changes go live without re-pasting anything in Squarespace.

Public by design: browsers load these files directly. Only website code lives here —
no internal docs, credentials or client data.

## Pages

| Folder | Website page | Squarespace Code Block |
| --- | --- | --- |
| `free-agent/` | developmentconsultingpartners.com/free-agent | paste `free-agent/squarespace-loader.html` |

## Updating a page

1. Edit `free-agent/source-embed.html` (the full single-file version; CONFIG is at the top of its script).
2. Rebuild: `python3 build.py free-agent/source-embed.html https://developmentconsultingpartners.github.io/site-embeds`
3. Commit and push to `main`. GitHub Pages updates within a few minutes (browsers may cache for up to 10).

Never edit `free-agent/agent.js` by hand: it is generated by `build.py`.
